# 发布来源与复现核验

这两个阶段来自本项目 2026-11-03 已完成实验的预处理规则和特征实现，整理为可在仓库根目录运行的 Python 包。没有依赖开发者电脑的绝对路径，不需要预先生成的私有特征缓存。

## 代码对应关系

| 发布文件 | 原实验实现 |
| --- | --- |
| `schema.py`、`preprocess.py` | `baseline_core.py` 的输入结构、患者筛选；`split_data.py` 的患者划分 |
| `features/baseline.py` | `baseline_core.py::features` 的 208 维基础特征 |
| `features/augmented.py` | `utility_features.py` 的 563 维特征，移除与本阶段无关的效用评估函数 |
| `features/recent.py` | `recent_features.py` 的 410 维对照特征 |
| `build_features.py` | 将原先本地缓存装配改为直接从原始 PSV 生成、校验并分批写出 |

增强特征的统计设计受到 Separatrix 思路启发，本项目为独立实现的调整版本：因果向前填充、修正的连续段长度、平方能量熵、部分窗口和原生缺失值。它不是原方法代码或其成绩的复现声明。

## 核验层次

1. 合成数据单元/集成测试：患者筛选边界、按患者分层划分、训练折隔离、完整小时保留、患者边界、特征维度、前缀不变性、标签拒绝、Unit1/Unit2 排除、缺失连续段、去时长对照和原始文件变更检测。
2. 全量原始数据预处理：核对 40,336 份记录，得到 39,874 名患者；逐人比较患者 ID、医院、事件状态、原文件校验值、集合及折号，与已完成实验一致。
3. 实际患者特征回归：跨 A/B 两院、三个集合，对普通、长记录阴性、长记录阳性患者逐元素比较两套特征和已保存的实验输入，同时检查前缀不变性。

公开的 `reports/` 只保存汇总核验信息。逐人清单、特征矩阵和本地日志放在被 Git 忽略的生成目录中。

Python 依赖版本见 `requirements.txt`。本阶段不做模型拟合；后续新增模型依赖应随训练代码另行提交。
