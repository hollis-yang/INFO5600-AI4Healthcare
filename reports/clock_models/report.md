# 时钟特征消融与统一单模型对比

沿用当前A+B完整记录研究：27,911训练患者、5,981验证、5,982测试；相同医院×事件分层患者名单、三折及内部15%校准患者。原始SepsisLabel不再次前移，完整记录包含可用发病后0–3小时。模型集成关闭。

## 结果解读

734维在固定测试集上略好：相对789维，ΔAUROC=+0.00020、ΔAP=+0.00452、ΔUS=+0.00553；但三项患者配对95%区间都包含0，US区间为[-0.00823,+0.01740]。训练CV的AUROC、AP、US又均略降，不能据此认定删除显式时钟能稳定提分。736维测试US反而下降0.00403。三模型主表因此继续遵守预先指定的共同789维口径。

统一789维后，当前设置下LightGBM在主三模型的三个测试指标上均领先。EBM相对LR的AUROC提高0.02106、US提高0.02841，两项配对区间均高于0；AP提高0.00946，但区间[-0.00518,+0.02388]包含0。EBM的US为0.40702，与LightGBM的0.41320接近，可保留为加性解释模型对照。补充XGBoost的AUROC略高于LightGBM，但AP和US较低。

150轮EBM的三折平均AUROC为0.83617、合并外折US为0.38518；300轮分别降至0.82620、0.37189，三折均退步。这说明在本组固定设置下，单纯延长EBM训练没有改善泛化。

删除显式时钟也没有消除长时段误报：734维在当前ICULOS>120小时的非septic报警小时比例，测试仍为88.26%、训练OOF为96.96%（789维分别为90.79%、92.93%）。保留的测量次数、测量间隔和累计生理统计仍可能代理时长，各候选校准阈值也影响报警率。这是病例较少时段的描述性观察，不能据此判定单一原因。

## 三模型的共同口径

主表预先指定共同789列信息，LR/加性EBM/LightGBM使用完全相同患者、小时、标签与评分方法；XGBoost为补充。不根据消融测试成绩替换公共特征。LR固定L2/C=1，无类别权重，仅拟合患者学习中位数及标准化，保留全缺失列为0。EBM原生NaN，interactions=0，单袋且validation_size=0，分箱只见拟合患者，禁用按小时随机验证；150/300轮固定候选按训练外折平均AUROC选择。原LGB/XGB789的3折和最终模型均核对参数/名单/列名后显式复用，其历史signature和SHA保留，并未伪造新拟合。

选中的EBM为`ebm150_789`。LR的迭代数是求解收敛信息，不作为调参轮数；最终仍使用C=1、max_iter=2000。树模型沿用此前训练内选定设置，本轮LR是一组预设基线、EBM是两组预算，并非对各算法进行对称的穷尽调参。

## 与proposal的关系

本轮补齐原proposal的LR/EBM/LightGBM架构对比，但使用当前A+B完整记录统一基准。原proposal的发病前六小时AUPRC、A开发/B迁移和6小时报警抑制是另一个研究终点；不能用此完整记录表替代原终点，或把旧312维LR/EBM成绩拼入新表。

## 复现与产物

```bash

.venv/bin/python -B scripts/verify_clock_models.py --final
```

完整指标见metrics.csv，消融与主表分别为clock_ablation_metrics.csv/model_comparison_metrics.csv；current_iculos_metrics.csv另报当前已知ICU时段的非septic误报与pre6小时命中。新模型与预测留在outputs/clock_models，列掩码/角色引用在processed_data/clock_models，无重复存储大特征矩阵。

拟合调度及取消的未完成预拟合记录见scheduling_events.json；这些未完成尝试没有参与候选选择或评分。

LR最终拟合只调整执行后端：JOBLIB_MULTIPROCESSING=0避免二分类单一求解任务的loky进程副本，VECLIB_MAXIMUM_THREADS=4。估计器仍保留n_jobs=4及相同C/L2/lbfgs/容差；历史CV模型不因执行后端调整而重训。运行配置见lr_execution_environment.json。

独立验证已通过：21个CV拟合、12个验证/测试评测及792条原生预测重放一致；LR四个拟合的789列中位数、标准化统计均独立复算通过，EBM加性约束、患者角色、精确阈值、官方US和冻结哈希均通过。见[独立验证记录](independent_verification.json)、[三折CV汇总](cv_metrics.csv)和[逐折指标](cv_fold_metrics.csv)。
